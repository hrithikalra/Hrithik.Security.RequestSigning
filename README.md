**Hrithik.Security.RequestSigning** provides HTTP-level request authenticity and integrity for ASP.NET Core APIs.

It works by building a deterministic canonical representation of each incoming HTTP request (method, path, query, headers, and body), verifying an HMAC-SHA256 signature generated by trusted clients, and rejecting any request that has been forged or modified in transit.

This library is designed for external APIs, partner integrations, mobile clients, and fintech systems where request authenticity is critical.

It is intentionally focused and does not replace authentication or authorization mechanisms such as JWT, OAuth, or mTLS. Instead, it complements them and is commonly used together with replay protection and other defense-in-depth security controls.
